# 地址不变前馈网络对照

循环 BC 初始化及多种 PPO 微调仍未达到稳定击败原神 AI 的水平。本候选检验现有
完整状态及动作历史输入下，不使用 LSTM 的前馈策略能否提供更好的 PPO 起点。
这不把循环状态陈旧预先认定为失败原因，也不缩减观测或动作空间。

配置 `pretrain_feedforward_address_invariant_demonstrations` 复用共享 PPO 工厂、
现有前馈监督训练入口及地址不变编码器。保留完整 590890 维输入、576 个动作、
原始与扩展教师数据集、完整对局划分、随机种子 341729、20 epoch、batch 256、
value 系数 .5、动作变化权重 1、学习率 .0003 和策略/价值 MLP [256, 256]。
删除 LSTM 后，每个监督批次为随机打乱的独立帧，不再采用四条 64 帧序列；因此
这属于架构与训练组织的整体比较，不宣称只改变一个张量或保持优化轨迹一致。
输入中的动作历史继续保留，双方座位仍使用同一个相对视角策略。

从头训练，按完整教师验证集 NLL 选择 best，规则与已有循环 BC 相同。
随后用同一八个世界种子、双座位的 16 局纯神 AI 开发验证比较初始强度；固定状态
拟合或单次耗时改善均不代替实战结果。不得直接把循环权重加载进不同架构，也不
根据这项监督训练宣称 PPO 更新或跨对手泛化已成功。后续 BR 仍复用共享 PPO，
不引入单独的前馈训练算法实现。

实际共享 learner CPU 预检通过。配置与循环控制的观测、封装、数据身份、种子、
监督预算及非循环网络参数一致；训练 227,277 帧、验证 78,544 帧。
前馈模型有 2,708,817 个参数，无 LSTM，使用完整动作头及现有稀疏缓冲区；
初始 Adam 为空、PPO 计数为零。初始参数哈希
`27e1a988925c35953cea5bac021a9857b45f3502c666c1237fa851cce46e83d1`。
证据 `logs/diagnostics/feedforward-address-preflight-20261003/summary.json`，脚本和
日志 `.dev/check-feedforward-address-20261003.{py,log}`。本次只新增配置，未修改
训练实现；预检不替代后续 GPU 训练或真实对局。
