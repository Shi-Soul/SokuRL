# 当前学习者轨迹上的原神 AI 教师

原地址不变 BC 的纯神 AI 16 局为 1 胜；两种自适应混合的中期均为 0/16，按局混合
最终仍为 0/16，平均对手掉血进一步下降。离线教师复习与冻结 BC 的在线 KL 约束也
没有得到强度提升。这里检验另一候选：在学习者实际访问的状态上，持续查询原规则教师，
每轮 PPO 后增加有预算的交叉熵更新。尚未证明有效，不把教师标签拟合当成战力。

研究动机来自 [Kickstarting](https://arxiv.org/html/1803.03835v1#S2) 的在线教师监督，
但该论文采用 IMPALA 联合目标，本实现是上游 PPO 后独立的 SGD 辅助步，不声称复现。
已有 DAgger 和恢复后缀 BC 的失败也仍成立；本候选没有修正原神 AI 的内部战术。

## 共享实现与语义

`rl=recurrent_online_teacher` 经共享工厂接入 BR、PPO、IPPO、NFSP、PSRO；DQN 拒绝此
PPO 辅助配置。共享 rollout buffer 的 add 边界读取学习者实际观测，保持上游 PPO 的
动作、回报、优势及更新实现。教师每个环境各有私有 actor，从第零帧逐帧推进，并在
新局重置；跨 rollout 保留记忆。God 的 `script=character` 根据自身视角选择角色脚本，
不会把灵梦对手脚本强行用作魔理沙教师。完整原状态、真实已执行动作历史均保留。

教师只提供标签，实际执行动作一直来自当前学习者。接口提供只读观测，越界或非整数
标签立即报错。这里的单动作交叉熵不等于已知完整教师分布的精确 KL，shadow teacher
在非自身控制轨迹上的标签质量也仍需实战验证。评估模型不加载教师或让教师接管。

窗口仅从本轮新采集的状态抽取、不跨局；压缩保留同局完整前缀，当前网络每次从零
重算前缀记忆，梯度只经过所选窗口。使用独立无动量 SGD，保留 PPO Adam 状态。
私有价值网络不参与辅助损失；共享编码器仍可能受影响，不能声称价值估计完全不变。
暂不允许同时叠加 rehearsal 或 online_anchor，避免把不同辅助目标混在一次对照中。

教师开局 RNG 与窗口抽样 RNG 分开保存，不使用全局 NumPy/Torch 随机流。
检查点保存教师指纹、配置、两条 RNG、各教师开局的槽位/seed/首查询编号/帧数、查询/
辅助预算及标签计数；继续训练严格核对
身份和设置，重新开局，不保存游戏或 Lua 现场。只加载权重时重置这些状态。普通上游
PPO/RecurrentPPO 可以直接加载产物推理，不需要教师文件。

日志 `teacher/*` 和 `timing.json` 的 `online_teacher` 记录采样 NLL/准确率前后值、
本轮与累计监督帧数、教师查询帧数/开局数、教师与实际动作一致率、前缀重放帧数和耗时。
查询时间计入采样，另记包含标签存储的采集总耗时；辅助更新时间计入更新。
监督帧含窗口重复抽样，不能与新增游戏帧混淆。
双方伤害/受伤、符卡动作进入、座位、角色和课程事件继续由原对局日志记录。

## 有限预算实机对照

先核对 CPU/CUDA、原脚本连续标签、跨局及跨 rollout 记忆、恢复和教师独立推理，
再经真实共享工厂预检配置。提交后才启动 GPU 训练。

`train_address_teacher_control` 与 `train_address_online_teacher` 都从同一原 BC 权重
和空 Adam 开始，固定魔理沙对原灵梦神 AI，均衡双座位、8 环境、256 帧 rollout、
batch=512、3 epoch、学习率 1e-4、gamma=1、GAE=.95、熵 .001、target_kl=.015、
7200 帧时限、完整 590890 维 float32 输入、576 动作、每帧决策、稀疏循环存储。
课程仍按长期 EMA 调整按帧 uniform 混合：起始 .5、半衰期 50 局、20 局预热、
逐局反馈、目标 .5、死区 .05、gain=.2、单次最多 .05；没有固定难度 stage。

两组配置仅辅助教师与输出目录不同，各 65536 步、32768 步存档。教师组每轮一次
SGD，学习率 .01、8 个至多 64 帧窗口；这是首个待检验预算，不声称最优。
完整训练后各做相同八世界 × 两座位的 16 局纯神 AI 验证，不以四局早停；教师辅助
标签不使用任何评估轨迹。相较旧随机座位长训练还改了座位采样和总预算，因此只能在
这对配置间隔离教师辅助的差别。没有强度收益则不直接延长同一配置。
