# PPO BR 训练的研究依据与待验证假设

这里区分论文结果、本项目证据和实验假设。论文中的胜率或资源效率不能直接移植成 SokuRL 的结论。

## 与当前探索瓶颈相关的示范学习

[Meisheri 等，Pommerman，2019，§3.2](https://arxiv.org/html/1911.04947v2#S3.SS2)
先模仿带噪启发式专家，再用 PPO 学习。文中指出切换到强化学习可能遗忘已有技能；
其实现将策略和价值网络分开，并使用逐渐加难的对手。论文还使用动作过滤，不能将全部收益
归因于预训练，且不是格斗游戏。

对本项目的推论：先用配对测评确认原魔理沙神 AI 能提供有价值的行为；若成立，可比较
“同一 PPO 模型的示范初始权重 + 自适应课程”和“从头 PPO + 相同自适应课程”。
示范预算要计入总环境交互预算，不能只比较微调步数。
PPO 初始权重应仍通过共享 RL 层加载，不能另外实现一个 MARL 专用 PPO。
监督验证应按完整对局划分，避免相邻帧泄漏；动作准确率不能替代真实对局胜率。
接入后需检查初始动作熵和价值拟合，防止转入 PPO 时行为立即退化。

[Pearce 与 Zhu，CSGO，2021](https://arxiv.org/abs/2104.04258)
研究了实时采样受限时的大规模行为克隆；其示范数据量达数百万帧。
它支持考察示范作为探索起点，但不支持少量样本必然足够、或本项目无需后续强化学习。

## 格斗游戏的泛化与训练规模

[Zhang 等，Shūkai，ICML 2024，附录 C–D](https://arxiv.org/html/2406.01103v1#A3)
使用 PPO 和异构联盟。其 QS 模型通过数值属性表达对手，减少对特定对手 ID 的依赖；
对手选择利用平滑胜率。附录配置为 n_steps=100、batch=5120、gamma=0.995、lambda=0.95，
并使用约 9000 CPU 核、1000 actor、每 actor 10 环境。其动作表示含动作掩码。

对本项目的推论：完整超人动作接口与采样规模不同，不能直接照搬超参数或论文样本效率。
跨角色泛化必须逐角色、逐座位检验；先在固定对手上获得可重复的胜率提升，再扩展对手池。
当前课程使用 EMA 反馈调整 uniform 替换概率，与该论文的对手抽样机制不同。
当前仍保留每帧全部 576 动作，不引入论文的动作掩码。

## 当前证据与下一步

截至自适应运行 40960 步，6 局混合对手训练为 2 胜 4 负，EMA 胜率约 0.3403，
uniform 概率仍为 0.90。原直接 PPO 和已完成的持续性候选在小样本完整神 AI 测评中尚未获胜。
优先积累当前自适应运行的长期反馈；规则基准输出为
`logs/benchmark/god-marisa-reimu-reference-20261001`，不能将其中规则候选成绩称为 PPO 成绩。
示范预训练尚未实现或验证，当前不是已证明有效的训练配置。
