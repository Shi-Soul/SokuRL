# 单次 PPO 更新的循环状态诊断

本实验不训练或控制游戏。比较地址不变 BC best 与两个真实首轮 1024 步 PPO 检查点，
在固定验证对局观测上测量：候选策略携带 BC 计算的旧 LSTM 状态，与候选策略从同一
历史重算状态后，下一段 64 帧的动作分布差异。两个分支使用完全相同的候选参数与输入，
区别只有段首隐状态；随后都按候选参数推进。

使用原教师、扩充教师和旧学习者三个已有固定验证集合；偏移为 0、256、1024、2048，
仅使用长度足够的完整 64 帧窗口。每次重算从整局开头的零状态开始，不将中途状态清零。
统计第一帧、窗口均值、最大值、末帧的总变差距离，并保留逐帧值。
偏移 0 的两个分支必须逐位相同；诊断前后参数哈希必须不变。

这里只检查 actor 记忆，不评判 critic。数据来自教师或旧学习者，不是本轮在线 PPO
实际访问的状态；一次首轮更新的结果也不能代表后续所有更新。
即使发现分布差异，仍不能由此证明它造成纯神 AI 退步，或证明重算记忆会增强策略。
背景与本地上游实现检查见[研究笔记](ppo-research-notes.md)。
