# 地址不变 PPO 的探索强度对照

[特征与 critic 对照](address-feature-split.md)中，四种模型所记录的平均动作熵只有
约 0.18–0.20；完整 576 类 uniform 分布的熵为 ln(576)，约 6.36。
这是当前分布集中程度的证据，不证明低熵本身造成失败，也不要求接近 uniform。
单独减小学习率、裁剪、拆分特征或校准 critic 均未稳定提高纯神 AI 胜率。
本轮检验在原初始化和 PPO 设置下，增加熵奖励是否能探索出更有效的动作。

`train_address_entropy_medium` 和 `train_address_entropy_high` 分别把 `ent_coef`
设为 0.01 和 0.1；原共享特征控制为 0.001。除熵系数与输出目录外，
配置、原 BC 初始参数、空 Adam、seed=1732、16384 步、两环境、网络、PPO 更新、
完整 576 动作、每帧决策、随机双座位、魔理沙对原灵梦神 AI、7200 帧上限均相同。
使用同一共享 RecurrentPPO 和 BR 入口，不新增 PPO 更新实现。

对手课程仍为长期 EMA 自适应比例，沿用原控制预热和反馈参数。短训练若不足预热局数，
应如实报告比例尚未变化，不能将其称为课程已生效。策略熵奖励与对手 uniform 混合是
不同机制，本轮不同时改变对手混合设置。

预先限定两项各 16384 步；各执行同一两世界种子 × 双座位纯神 AI 四局筛查。
有胜局再扩展 12 局。熵上升、训练 loss 或伤害改善不能替代严格胜率。
高熵可能破坏已学会的动作时序；不因探索指标上升自动延长训练。
