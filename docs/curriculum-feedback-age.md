# 并行对局下的自适应课程反馈滞后

复查两个已结束的 262,144 步混合实验，比较完成局启动时的课程计数与结束时计数。
这量化的是完成顺序导致的反馈年龄，不是新的训练或反事实胜率实验。
数据来自 `br-address-{action,episode}-mix50-20261002/progress.json`；重新逐局计算
长期 EMA 与原事件一致，原始文件 SHA256、每局记录和摘要保存在
`logs/diagnostics/curriculum-feedback-age-20261003/summary.json`。

两组均为 8 个并行环境，半衰期 50 局、20 局预热，之后每完成一局更新比例。
每局保留启动时的概率，因此较晚完成的局可能仍采用旧难度；快速完成的环境也可能
在另一个环境一局结束前完成不止一局，反馈年龄不保证小于环境数。

起始概率均为 .5。按帧组首次完成的新比例局实际使用 .403747，结束前控制器却已
降到 .289946；该局失败，EMA 仍为 .586422，控制器继续降至 .282661。
这是现有规则对长期平均的真实响应，不是按错座位或把并行结束顺序写错。

由此可提出一个待验证配置：保持 EMA 每局更新，增大现有 `update_every`，减少在
尚未观察新难度结果前重复改变概率的次数。它仍完全按长期表现调整，不引入固定 stage。
较慢调整也可能妨碍跟上策略进步；上述旧轨迹不能用来预测改动后的对局或证明收益。
尚未运行新频率的配对实战，不据此修改已有训练结果或认定它是失败的主因。

早期循环状态旁路诊断显示采样边界差异较小且迅速衰减，见
[循环状态核对](recurrent-state-audit.md)。这支持将反馈频率列为比全历史状态重算
更低成本的后续候选，但不排除后期训练的其他循环状态问题。
