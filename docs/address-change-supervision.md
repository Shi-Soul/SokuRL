# 地址无关编码下的动作变化帧监督

当前原 BC 在完整教师验证集上准确率约 94.56%，动作变化帧仅约 65.56%；在另一个
学习者的固定轨迹上变化帧准确率约 7.34%。总体准确率不能单独代表顺利完成动作
切换或实战强度。此候选检验改变离线监督权重是否改善初始化，仍使用共享 PPO 网络。

[旧数值编码器的配对实验](action-change-supervision.md)中，权重 4 未改善四局实战。
其后确认旧网络依赖无游戏语义的绝对进程地址；本次仅在已验证的地址无关编码器下
重新检验同一假设，不把旧失败隐藏，也不假定新编码器使加权必然有效。

配置 `pretrain_address_change_control` 与 `pretrain_address_change_weighted` 除输出
和 `pretraining.action_change_weight`（1 / 4）外一致。两者从同一个原 BC best
加载权重并重建优化器，相同 seed=341729、原教师两份数据、227,277 个训练帧、
78,544 个验证帧、5 个 epoch、batch=256、循环窗口 64、value_coef=.5。
完整观测、576 动作、逐帧控制、角色与教师身份不变，没有生成新的游戏训练数据。

沿用共享实现：按真实有效帧加权 NLL，排除填充帧，价值目标不加权。
各组按预先指定的验证加权 NLL 选择 best（允许选 epoch 0），记录普通和变化帧
指标。不同权重的选择分数不直接横比；两组都以同一 8 个世界种子、双座位的
16 局纯神 AI 开发验证判断实战，保持策略种子及对手名称不变。
该种子集已被用于多轮开发，不能视为独立测试。

只有实战显示值得继续的信号，才将候选接入同条件共享 BR/PPO 对照；离线拟合
改善本身不足以采用新初始化。若仍无实战改善，保存结果而不自动延长加权训练。
